# Customer Remaining Pages

## Feature Overview
Implement the remaining pages for the Customer portal based on the `3_customer_all_remaining_dark.html` template. These pages include:
- **Billing & Payments** (`/customer/billing`): Transaction history and saved payment methods.
- **My Profile** (`/customer/profile`): View and edit personal information.
- **My Reviews** (`/customer/reviews`): Pending reviews to submit and history of past reviews given.
- **Settings** (`/customer/settings`): Notification preferences, appearance, security, and account deletion.

## Components
- `BillingPage`
- `ProfilePage`
- `ReviewsPage`
- `SettingsPage`

## API Endpoints
- These pages can use static mockup data in the frontend for now, or lightweight backend endpoints if data is dynamic.
