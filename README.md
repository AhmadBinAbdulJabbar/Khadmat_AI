# Khadmat_AI
Agentic AI platform for Pakistan's informal service economy. Book plumbers, electricians, AC technicians &amp; more in Urdu, Roman Urdu, or English — powered by Google Antigravity. Built with Next.js, FastAPI, and Supabase.
